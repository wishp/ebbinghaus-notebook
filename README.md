# 艾宾浩斯错题本

个人使用的手机 / iPad 复习应用，支持语文生字、语文拼音、英语词句。

使用 Safari 打开 GitHub Pages 网址，点击分享 → 添加到主屏幕。首次联网打开后可离线复习。

修改应用后，需要先发布到本仓库。同时更新 app-version.js、version.json 的版本与 build，以及 sw.js 的 CACHE 标识。手机联网后点击个人中心 → 版本更新，下载并切换到新版本，保留本设备学习数据。

错题、历史、草稿和设置保存在当前浏览器的 localStorage 中，不上传 GitHub，不会跨设备自动同步。清除浏览器网站数据会删除记录。英语翻译在本地词库无法匹配时使用外部翻译服务，需要联网。

GitHub Pages 使用 main 分支根目录。vendor/pinyin-pro/LICENSE 保留第三方许可。
